# Spec Delta

## ADDED Requirements

### Requirement: 新增通道对话框不得预填通道 ID

ChannelListView 的「新增通道」对话框打开时，`channel_id` 输入框 MUST 为空，不得预填任何值。

- 输入框 placeholder MUST 为 `留空自动生成（20位国标编码）`
- 用户保留为空提交时，前端发送的请求体不包含 `id` 字段（而非发送空字符串），由后端自动生成 20 位合规 ID
- 用户手动输入时，前端 MUST 校验恰好 20 位纯数字，校验失败时不提交并提示用户
- 保存成功后，前端从响应中读取实际分配的 ID（`auto_generated: true` 时）并展示给用户

#### Scenario: 用户保留通道 ID 为空时后端自动生成

- **WHEN** 用户在「新增通道」对话框中保留通道 ID 为空，输入 name 后点击保存
- **THEN** 前端发送的请求体为 `{"name":"Cam-1","status":"ON"}`（不包含 `id` 字段）
- **AND** 前端接收响应后，若 `auto_generated: true`，在成功消息中展示实际生成的 ID
- **AND** 通道卡片列表刷新后展示新生成的 20 位 ID

#### Scenario: 用户手动输入通道 ID 时的校验

- **WHEN** 用户在「新增通道」对话框中手动输入通道 ID
- **THEN** 前端实时校验输入值，若不是恰好 20 位纯数字则禁用提交按钮并显示提示
- **AND** 提交时后端收到完整的 20 位 ID，响应 `auto_generated: false`

### Requirement: 通道媒体源编辑入口可从卡片直接操作

通道卡片的操作区域 MUST 提供「上传媒体」按钮，点击后直接打开上传对话框，无需进入嵌套菜单。

- 上传成功后，前端自动将返回的容器内路径填充到该通道的媒体源配置中
- 媒体源编辑成功后，通道卡片刷新显示当前配置的类型和路径

#### Scenario: 从通道卡片直接上传媒体文件

- **WHEN** 用户在通道列表页面点击某通道卡片的「上传」按钮
- **THEN** 弹出的上传对话框标题包含该通道 ID
- **AND** 上传成功后，通道卡片刷新后媒体源状态显示为「已配置」
