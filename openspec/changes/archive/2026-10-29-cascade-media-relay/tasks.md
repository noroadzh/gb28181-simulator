- [x] 1.1 允许显式会话键：抽 `startLiveWithKey(ctx, key, node, channel, transport)`，`StartLive` 用 (node, channel) 包装；会话登记与结束沿用现有路径。验收：单测断言同一通道可用不同键并存，各自 stop 互不影响
- [x] 1.2 中继表：上级 Call-ID →（下级 Call-ID、发送 sink、接收端口、通道），支持并发安全的新增/查找/删除。验收：单测覆盖新增、查找、并发删改

## 2. INVITE 分派与双对话

- [x] 2.1 平台实时视频 INVITE 分派：`m=video` 且 `To` 指定通道且能解析到下级时走中继；解析不到时保持既有通用应答（逐字节不变）。验收：单测覆盖有下级/无下级/多下级
- [x] 2.2 上级腿应答：平台开接收端口，返回 200 + sendonly SDP（UDP 或附录 D TCP，反射平台实际接收传输）；未建立下级前不得先回 200。验收：单测断言 200 的 SDP 端口有效、失败时状态码正确
- [x] 2.3 桥接：订阅下级会话 PS 帧，经 RTP 打包发到上级端点；发送失败即结束中继。验收：单测断言上级 UDP socket 收到以 PS 头开头的 RTP

## 3. 失败与终止

- [x] 3.1 失败映射：不可达 502、拒绝 480、超时 504、无目标 404；失败路径释放已开端口。验收：单测逐项覆盖并断言端口已释放
- [x] 3.2 成对终止：上级 BYE → 向下级发 BYE 并清理；下级 BYE → 向上级发 BYE；CANCEL/超时同路径。验收：单测断言两个方向都发出 BYE、中继表清空
- [x] 3.3 并发多上级：同一通道两条中继各自独立，停一条不影响另一条。验收：单测断言两条流各自到达、单独 stop 只影响自己
