# Docker 发布到 10.96.1.125

## 状态：✅ 已完成（2026-10-08）

## 需求概述

将 gb28181-simulator 打包为一个版本，基于 Docker 部署发布到 10.96.1.125 服务器，并在服务器 `/slow2` 目录下新建一个文件夹存放 Docker 执行脚本，打包后的程序也一并上传到该文件夹。

## 澄清确认

- 上传方式：SSH + scp
- 服务器路径：`/slow2/gb28181-simulator`
- 部署拓扑：2 节点（platform-large + device）
- 版本号：git 短 commit `8e55379`
- Docker 环境：服务器本地构建镜像

## 实施结果

### 部署拓扑

| 节点 | SIP 端口（宿主机） | HTTP 端口（宿主机） | 节点 ID |
|------|--------------------|---------------------|---------|
| gbsim-platform | 15060 | 18080 | 34020000002000000001 |
| gbsim-device | 15061 | 18081 | 34020000001310000001 |

### 媒体源

- **capture 配置**：platform 与 device 的 `config.yaml` 均已添加 `capture: enabled: true; capacity: 2048`
- 抓包 API：`GET /v1/nodes/:id/capture` 返回正常空数组，不再报 "capture store not configured"
- pcap 导出：`GET /v1/nodes/:id/capture.pcap` 可用

### 遇到的问题与修复

| # | 问题 | 修复 |
|---|------|------|
| 1 | SSH root 登录被拒（id_rsa 密钥） | 改用默认密钥（无 `-i` 参数） |
| 2 | 服务器 8080 端口被 pansecurity-gateway 等占用 | 改为 platform 18080 / device 18081 |
| 3 | platform 容器不健康：permission denied | 在 deploy.sh 中 `chown -R 10001:10001` 数据目录 |
| 4 | depends_on 阻塞 device 启动 | 去掉 `depends_on` 的 `condition: service_healthy`，保留 healthcheck 仅用于监控 |
| 5 | "capture store not configured" 报错 | 配置文件添加 `capture: enabled: true` |
| 6 | bind mount 配置变更后容器未重启 | 使用 `docker compose restart` 强制重启 |
